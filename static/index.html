ZETESIS / NOTES

Notes

Double-click anywhere to add a box.
Drag from a box's dot to another box to join them.
Right-click a box for a note about it.

New note

A PDF, a Markdown, Org or text file, or any other file. You can also drop it here.

Shortcuts

⌘ L
Search all notes (also ⌘ K)
⌘ F
Search the folder you're in. In a note, find text in the note; in Roadmap, find boxes
⌃ N ⌃ P
Next or previous result, note, or item (or ↓ ↑)
Enter
Open it, check an item off, or save an edit
Esc
Go back a level: an Explore area to Explore, a folder to the one above, then to search. In a note, it closes the note
e
Edit or rename
⌥ ↑ ⌥ ↓
Move the selected item (Explore)
⌫
Delete the selected item (Explore), or box or arrow (Roadmap)
n
Add an item (Explore)
# name
Typed in an add box, makes a section (Explore)
⌘ S
Save the open note now
/
Insert a block, in a note
n or double-click
Add a box (Roadmap)
Tab
Add a box joined to the selected one (Roadmap)
⇧ Enter
New line in a box (Roadmap)
Right-click
Open or close a box's note (Roadmap)
